Before you start

Close Lineage II. Use a separate game folder and leave enough free space for both the downloaded archives and the extracted files. Keep another server’s client separate.

FIRST INSTALLATION

From download to character selection

  1. 01

    Download & extract the Game Client

    Wait for the download to finish. Extract the complete archive into a new folder, for example:

    C:\Games\L2Counter\
  2. 02

    Find the game folder

    Open the extracted folders until you see System beside the other game folders. This is the client root: the folder where the patch belongs.

  3. 03

    Apply the Full Server Patch

    Extract the patch separately. Open it until you see its System folder. Copy the CONTENTS into the client root, merge matching folders and replace matching files when Windows asks. Do not copy the ZIP/RAR archive itself.

  4. 04

    Launch the patched game

    Open System and run L2.exe from this COUNTER installation. You can create a shortcut to that file. Do not use an old shortcut or another server’s launcher.

    C:\Games\L2Counter\System\L2.exe
  5. 05

    Sign in & choose COUNTER

    Use your game account and choose COUNTER when the server is open. Game-account creation instructions will be published before launch. The website’s preview Account/Admin pages are not game-account registration.

This is where the patch goes

Example after extraction. Your folder name or drive can be different.

C:\Games\L2Counter\

    └── L2.exe
Correct

The patch’s System folder merges with the client’s System folder.

Avoid a second System folder

Do not paste the entire patch folder inside System. That creates an extra folder instead of updating the game files.

ALREADY INSTALLED

Updating an existing COUNTER client

  1. 01

    Close the game

    Exit Lineage II before replacing files. Keep a backup of your working installation or the files you will replace.

  2. 02

    Check the update requirements

    Use Update Only only on the COUNTER version named in its release instructions. If your version is unknown or too old, use the latest Full Server Patch on a compatible client.

  3. 03

    Extract, replace, restart

    Extract the update, copy its contents into the same client root and replace matching files. Start System\L2.exe again. The update does not replace the Game Client.

Something not working?

Do I need all three downloads?

For a fresh installation, use Game Client + Full Server Patch. Update Only is for an existing supported version. Install an additional update after the full patch only if the release instructions explicitly require it.

The archive will not extract or reports a CRC error.

Check that the download finished. Re-download a damaged archive and use an extraction program that supports its format. If the release has multiple parts, download every part into the same folder first.

L2.exe is missing or a DLL error appears.

Make sure extraction completed and the patch was copied into the correct client root. Do not mix System files from other clients or download random DLLs. For a mixed installation, start with a fresh client in a separate folder.

The wrong server opens or I cannot log in.

Check the shortcut path and apply the COUNTER patch to the folder you actually launch. Confirm that the server is open and that you are using a game account. Do not edit connection files with settings from another server.

Windows or my antivirus blocks a file.

Do not disable your antivirus or ignore a warning. Stop and ask the COUNTER team to verify the exact file and its checksum. Use only files linked from this Download page.
